# Contributing to Karn

Bug reports and pull requests are welcome, including human-written and
AI-generated contributions.

## Bring a minimal reproduction

Bug reports and bug-fix PRs must include the smallest example that reproduces
the problem. Give the repository revision, starting position or inputs, exact
actions or command, actual result, and expected result. For a rules dispute,
cite the relevant Comprehensive Rule, pinned Oracle text or ruling.

A small MGN record, focused rules test, executable script, or reproducible
position and action sequence is suitable. See [MGN](docs/mgn/README.md) and
[testing](docs/testing.md). Keep unrelated cards and actions out of the example.

Behavior-changing PRs should include a regression test that fails before the
fix and passes afterward. For other changes, provide a small example showing
the problem and the proposed improvement, with the checks you ran.

## AI-generated submissions

AI-generated analysis or code submitted in a bug report or PR must use
**Fable or Astra, or their successors, with thinking/reasoning set to high or
higher**.

Include the provider, exact model/version, thinking or reasoning setting, and
which parts of the submission were generated by AI. These details are
self-reported. Reviewers judge the reproduction, rules evidence and change
itself. The submitter is responsible for the accuracy of the report and patch.

Human-written contributions do not require AI model metadata.
